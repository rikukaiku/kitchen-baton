# キッチンバトン 機能一覧

作成日：2026-08-22
デモ：https://kitchen-baton.vercel.app

## 地図・検索

- 東京都・埼玉県の子ども食堂、公民館等の公共施設を地図上にピン表示（現在約1,600件）
- 種類ごとにピンの色を分けて表示（子ども食堂＝青、公民館等＝緑）
- ピンが密集する箇所は自動的に件数表示にまとめ、ズームすると個別ピンに分解（見やすさ重視）
- キーワード検索（施設名・住所・支援内容）
- 都道府県・市区町村での絞り込み（実データから自動生成、五十音順に整理）
- 「場所の種類」を複数選択して絞り込み（例：子ども食堂と公民館を同時に表示）
- 検索結果カードをクリック → 地図が該当ピンに移動し、吹き出しが自動で開く
- 「リセット」ボタンで表示位置・検索条件を初期状態に戻せる
- 初期表示は東京都庁付近（23区のほぼ中心）

## データ

| データ | 件数 |
|---|---|
| 子ども食堂（東京都） | 798件（区市町村オープンデータ＋東京都福祉局データを統合） |
| 子ども食堂（埼玉県） | 197件 |
| 公民館・区民館・地区センター等 | 627件（「市民が借りられる公共の場所」として抽出） |

- すべてCC BY 4.0のオープンデータを使用、出典を明記（`data/SOURCES.md`）
- 電話番号・メールアドレス等の個人連絡先情報は、公開データからは除外

## 分析

- 区市町村ごとの0〜14歳人口と子ども食堂数を掛け合わせた空白地域（ギャップ）分析
- 食堂ゼロの区市町村を検出（新宿区・墨田区など人口の多い区も含めて25件判明）

## 技術構成

- フロントエンド：React + TypeScript + Vite、地図はLeaflet
- ホスティング：Vercel
- データ収集：Pythonスクリプトで東京都オープンデータカタログから自動収集（再利用可能な手順をClaude Codeの「スキル」として整備済み）
